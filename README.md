## Sentiment Analysis of Tweets on IKN Budget
A machine learning project for classifying sentiment in Indonesian tweets discussing the budget and development of Indonesia's New Capital (Ibu Kota Nusantara).
```
The project focuses on text preprocessing, TF-IDF feature extraction, class imbalance handling, and comparison of several machine learning classification models.
```

### Overview
This project applies Natural Language Processing (NLP) and machine learning techniques to classify tweets into three sentiment categories:
```
- Positive
- Neutral
- Negative
```
The workflow includes:
```
- Data cleaning and preprocessing
- Text normalization
- Tokenization and stopword removal
- TF-IDF feature extraction
- Handling class imbalance using SMOTE
- Machine learning model training
- Model evaluation and comparison
```

### Models
```
- Support Vector Classifier (SVC)
- Logistic Regression
- SGD Classifier
- Random Forest
- Stacking Classifier
```
